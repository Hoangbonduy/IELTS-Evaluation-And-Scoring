# IELTS-Evaluation-And-Scoring

Đây là công cụ hỗ trợ đánh giá và chấm điểm bài viết IELTS, giúp phân tích bài viết dựa trên các tiêu chí như Task Response, Coherence, Lexical Resource, và Grammar Range & Accuracy.

## Cài Đặt

1. Clone repository:
   git clone https://github.com/Hoangbonduy/IELTS-Evaluation-And-Scoring.git

2. Chuyển vào thư mục dự án:
    cd IELTS-Evaluation-And-Scoring

3. Cài đặt dependencies:
    pip install -r requirements.txt


### Hướng Dẫn Sử Dụng
- Chạy script để đánh giá bài viết IELTS:
    python evaluate_iets.py --input_path path/to/essay.txt --output_path results.csv


#### Các Tính Năng Chính
- Tự động chấm điểm bài viết IELTS Task 1 và Task 2.
- Phân tích lỗi ngữ pháp và từ vựng.
